# Nagendra.Dev — Portfolio starter

A responsive black-and-purple portfolio built with HTML, CSS and vanilla JavaScript.

## Run it in VS Code
1. Extract this ZIP.
2. Open the `nagendra-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or install the **Live Server** extension.
4. Right-click `index.html` and choose **Open with Live Server**.

## Folder contents
- `index.html` — page structure and portfolio content
- `style.css` — responsive dark-purple design and 3D-style effects
- `script.js` — scroll reveal, progress bar, avatar tilt and mobile menu
- `assets/developer-3d.png` — generated 3D developer avatar
- `assets/photo-1.jpeg` ... `photo-5.jpeg` — your uploaded photos

## Before publishing
- Check that your phone number and email are correct.
- Add your real GitHub and LinkedIn profile links when ready.
- Add a `resume.pdf` file in `assets/` and a download link if you want visitors to download it.
- Add repository links to the project cards only when the repositories are public and ready.
- The skill bars are visual design elements, not measured proficiency scores.

## Notes
The reference video is used as visual inspiration for cinematic, scroll-driven motion. This starter uses CSS 3D perspective and JavaScript interactions rather than reproducing the video's exact source code or assets.
